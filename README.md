Day 11-12 CAP Assignments
This repository contains SAP CAP (Cloud Application Programming Model) assignments developed during training and practice.

## Assignments Included

* Assignment 1 – Hospital Management System
* Assignment 2 – University Registration System
* Assignment 3 – Fleet & Delivery Management System

* CDS
* Node.js
* OData V4

* Service definitions
* CSV sample data
* `test.http`
